# Color-Palette-Generator

As someone with a design background, I was interested in aligning my first coding project with something already familiar to me: web colors and color theory. This page will allow users to generate a color palette using either HEX or RGB codes and according to scheme preference--that is, whether they want the palette to be complementary, monochromatic, triadic, or tetradic, with a maximum number of five colors per palette.
